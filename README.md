Project Overview: Habiba Ruhi Portfolio  
This is a modern, one-page portfolio website built for a frontend developer. It is designed to be clean, fast, and professional, acting as a digital resume.  

Key Highlights  
Single-Page Speed: Sections like About, Skills, and Projects load instantly without refreshing the page.  
One-Click CV: Includes a "Get CV" button that automatically creates and downloads a professional PDF resume.  
Modern Look: Uses a dark theme with smooth animations and a "glass" effect for a high-end feel.  
Live Projects: Showcases web applications, such as a Typing Test App and a personal portfolio.  

Technology Used  
HTML5 & CSS3: For the structure and the sleek dark-mode styling.  
JavaScript: Manages the page content and interactive elements.  
jsPDF Library: A specialized tool used to generate the downloadable resume.  

Why It Works  
Professional: It highlights specific skills like HTML, CSS, JavaScript, Flask, and Node.js.  
Organized: Displays work experience and projects in a clear, easy-to-read layout.  
Accessible: The design is fully responsive, meaning it works perfectly on both phones and computers.
